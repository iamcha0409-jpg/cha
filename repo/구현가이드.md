# 구현 가이드: 선불카드사 이용건수 원천 데이터 자동 취합

- 관련 문서: BRD.md, PRD.md, 검증기준_테스트케이스.md
- 구현물: `파워쿼리\` 폴더의 코드 6개 (메모장으로 열어서 복사·붙여넣기)
- 테스트용 가짜 데이터: `테스트데이터\` 폴더 (케이스별 폴더 12개 + `기대결과.xlsx`)

---

## 0. 준비

> **매주 운영 (2026-11-18 변경)**: 사내 시스템 [엑셀 다운로드] → 원천 폴더에 저장(이름 그대로) → [모두 새로고침]. 최신 파일은 **파일 수정 시각**(내려받은 시각)으로 판단합니다. **원천 파일은 열어서 저장하지 마세요.** 저장하면 그 파일이 최신으로 취급됩니다.
> 테스트데이터 폴더를 복사할 때도 수정 시각이 유지되도록 **탐색기로 복사**하세요. (T02·T07은 파일 수정 시각 순서가 맞아야 기대결과대로 나옵니다.)

1. 이 폴더(`최종`)를 내부망 PC로 옮깁니다. 내부망으로 들여오는 것은 승인이 필요 없습니다. (내부망에서 밖으로 내보낼 때만 사전승인 필요)
2. 쿼리를 만드는 방법은 모든 단계에서 같습니다.
   - 엑셀 [데이터] > [데이터 가져오기] > [기타 원본에서] > [빈 쿼리]를 누릅니다. 파워 쿼리 편집기가 이미 열려 있으면 [홈] > [새 원본] > [기타 원본] > [빈 쿼리]를 누르면 됩니다.
   - [홈] > [고급 편집기]를 열고, 안의 내용을 모두 지운 뒤 해당 `.txt` 내용을 붙여넣습니다.
   - 오른쪽 '쿼리 설정'의 **이름**을 파일 첫 줄의 `[쿼리 이름: …]`과 **똑같이** 바꿉니다. 이름이 다르면 다른 쿼리가 찾지 못합니다.

## 1단계 MVP: 파일 결합, 임시 파일 제외, 형식 지정 (F1·F2·F3)

| 순서 | 파일 | 쿼리 이름 | 로드 방식 |
|---|---|---|---|
| 1 | `0_설정.txt` | 설정 | 연결만 만들기 |
| 2 | `1_원천_파일목록.txt` | 원천_파일목록 | 연결만 만들기 |
| 3 | `2_원천_전처리_1단계.txt` | 원천_전처리 | **표로 시트에 로드** (확인용) |

- `설정`의 `원천폴더`를 먼저 **`테스트데이터\T01_기본취합` 폴더의 전체 경로**로 바꿉니다.
- [닫기 및 다음으로 로드]를 누르고 위 표의 로드 방식을 고릅니다.

**확인**: 시트에 **9행**(11/01~11/09)이 가로형으로 나오고, 기준일은 날짜, 카드사 열은 숫자로 보이면 통과입니다.

**확인**: T01 기준 **36행**, 열이 `Source.Name | 수정시각 | 기준일 | 카드사 | 이용건수`이면 통과입니다.

## 5단계: 일별·월별 점유율 (F8·F9)

| 파일 | 쿼리 이름 | 로드 방식 |
|---|---|---|
| `6_일별점유율.txt` | 일별점유율 | **표로 새 시트에 로드** (시트 이름: 일별점유율) |
| `7_월별점유율.txt` | 월별점유율 | **표로 새 시트에 로드** (시트 이름: 월별점유율) |

**확인**: `원천폴더`를 `T02_지난수치수정`으로 두고 새로고침하면 다음과 같이 나와야 합니다.
- 일별점유율: 10행. 2026-11-08 선불카드사1 점유율 = **24.68%**, 선불카드사2 점유율 = **25.84%**, 선불카드사2 건수 = **1,132**. 모든 날 점유율 합계 100%
- 월별점유율: 1행(2026-11). 선불카드사1 점유율 = **24.94%**, 기준일수 10

점유율이 `0.2468`처럼 소수로 보이면 해당 열을 선택하고 [홈] > [백분율 스타일]을 누르면 됩니다.

## 6단계: 점유율현황 (일별 + 그달 마지막 날 아래 월 점유율, F10)

| 파일 | 쿼리 이름 | 로드 방식 |
|---|---|---|
| `8_점유율현황.txt` | 점유율현황 | **표로 새 시트에 로드** (시트 이름: 점유율현황, 보고용 메인 시트) |

- 일별점유율·월별점유율 시트는 그대로 두어도 되고, 필요 없으면 두 쿼리를 **연결만 만들기**로 바꿔도 됩니다. 점유율현황은 이 두 쿼리를 참조하므로 쿼리 자체는 지우면 안 됩니다.
- **월 줄 강조 (한 번만 설정)**: 점유율현황 표 전체를 선택 → [홈] > [조건부 서식] > [새 규칙] > [수식을 사용하여 서식을 지정할 셀 결정] → 수식 `=$A2="월"` → 서식에서 굵게·채우기 색 지정. 새로고침해도 유지됩니다.

- **열 구성**: 구분(A) · 기준일(B) · 선불카드사1~4 건수(C~F) · 건수 합계(G) · 선불카드사1~4 점유율(H~K) · 점유율 합계(L) · 상태(M) · 전일대비 2배 초과(N)
- **전일 대비 2배 초과 음영 (한 번만 설정)**: `C2:F끝`과 `H2:K끝`을 Ctrl로 함께 선택 → [조건부 서식] > [새 규칙] > [수식을 사용하여…] → 수식
  `=AND($A2="일",ISNUMBER(SEARCH(SUBSTITUTE(SUBSTITUTE(C$1," 건수","")," 점유율","")&",",SUBSTITUTE($N2," ","")&",")))`
  → 채우기 색(예: 주황) 지정. 건수 칸과 점유율 칸이 함께 칠해집니다. 열 위치가 다르면 `$N`을 `전일대비 2배 초과` 열 문자로 바꾸세요.
- **음수 값**: 쿼리가 결과에서 자동으로 빼고, 검증 시트 "음수 값 (결과에서 제외)"에 개수를 표시합니다.

**확인**: `원천폴더`를 `T13_더미10건`으로 두고 새로고침하면 다음과 같이 나와야 합니다.
- `2026-10-31` 바로 아래에 `2026-10 월 합계`, `2026-11-07` 바로 아래에 `2026-11 월 합계` 줄
- 2026-11-04 건수 합계 = 1,252,037, 2026-11 월 합계 줄 건수 합계 = 1,269,503
- 11월 줄 상태: "기준일 7일, 카드사 누락 2일" (11/06은 음수 제외, 11/07은 N/A)
- **2026-11-04 선불카드사1·선불카드사4의 건수 칸과 점유율 칸에 음영** (1,210→1,250,000 / 0→405), 다른 칸은 음영 없음
- 2026-11-06 선불카드사3 빈칸, 검증 시트 "음수 값 = 1"

## 5. 테스트데이터로 전체 점검 (사람 확인)

`설정`의 `원천폴더`를 케이스 폴더로 바꿔 가며 [모두 새로고침]을 누르고, `기대결과.xlsx`의 같은 이름 시트와 비교합니다. 시간이 없으면 ★ 표시된 5개만 해도 됩니다.

| 케이스 | 엑셀에서 볼 것 | 기대 값 |
|---|---|---|
| ★ T01 | 취합결과 행 수 / 종합 판정 | 36 / 정상 |
| ★ T02 | 11/08 선불카드사2 값 / 수정 반영된 값 | 1132 / 1 |
| T03 | 이용건수가 숫자로 보이는지 (왼쪽 정렬이면 텍스트) | 12행, 숫자 |
| T04 | 카드사 목록 | 선불카드사1~5 |
| T05 | 새로고침 오류 없이 결과가 나오는지 | 12행, 정상 |
| ★ T06 | 제외된 파일 / 행 수 | `메모.csv` / 12 |
| T07 | 11/03 선불카드사1의 Source.Name / 판정 | `시스템다운로드 (1).xlsx` (수정 시각이 더 늦은 파일) / 정상 |
| T08 | 기준일 없는 값 | 4 |
| ★ T09 | 형식 오류 값 / 행 수 | 5 / 11 |
| T10 | 카드사 누락 기준일 | 1 |
| ★ T11 | 새로고침 오류 메시지 | "…'우리카드(가칭) 점유율 현황' 시트를 찾을 수 없습니다." |
| T12 | 새로고침 오류 메시지 | "…필수 열이 없습니다 → 선불카드사4" |
| ★ T13 | 점유율현황 음영 / 음수 값 / 결과 행 수 | 11/04 선불카드사1·4 음영 / 1 / 30 |

> T11·T12는 **오류가 나야 정상**입니다. 오류를 확인한 뒤에는 `원천폴더`를 정상 폴더로 되돌리세요.

## 6. 실제 데이터 적용 후 사람이 확인할 결과값

자동 검증 시트가 "정상"이어도, **처음 적용할 때 한 번**은 아래 항목을 직접 확인하세요.

| # | 확인 항목 | 방법 | 왜 사람이 봐야 하나 |
|---|---|---|---|
| H1 | **값 대조** | 아무 기준일 하나를 골라, 원천 파일의 4개사 값과 취합결과 값이 같은지 비교 | 숫자가 엉뚱한 열에 들어가는 실수는 개수 점검으로 잡히지 않음 |
| H2 | **수정값 반영** | 수정된 적 있는 기준일 하나를 골라 **가장 최근 파일의 값**과 같은지 비교 | BRD 성공 기준 3 |
| H3 | **기간 빠짐** | 검증 시트의 "기준일 범위"가 예상 기간과 맞는지, 중간에 빠진 주가 없는지 | 파일을 안 넣은 주는 오류가 나지 않음 |
| H4 | **카드사 목록** | 정확히 선불카드사1~4만 있는지 (`비고` 같은 다른 열이 섞이지 않았는지) | 기준일 외의 모든 열을 카드사로 보도록 설계함 (D11) |
| H5 | **행 수 감각** | 결과 행 수 ≈ 기준일 수 × 4 | 큰 누락이나 중복을 빠르게 감지 |
| H6 | **"확인 필요" 원인** | 판정이 "확인 필요"면 해당 항목을 보고 원천 파일을 고친 뒤 다시 새로고침 | 원인 판단은 사람이 해야 함 |
| H8 | **점유율 손계산 대조** | 한 달을 골라 카드사1 이용건수 합 ÷ 4개사 합을 계산기로 직접 계산해 월별점유율과 비교 | 계산식이 의도대로인지 (일별 평균이 아닌 합계 기준) |
| H9 | **음영 칸 원인 확인** | 음영이 칠해진 날은 원천 파일에서 그 카드사 이용건수가 실제 증가인지, 입력 실수인지 확인 (실수면 사내 시스템 수정 후 다시 내려받기) | 2배 초과는 표시만 하고 값은 그대로 계산에 들어감 |
| H7 | **소요 시간** | 실제 운영 1회에 걸린 시간 측정 (내려받기 + 저장 + 새로고침) | BRD 성공 기준 5: 주 30분 이내 |

## 7. 자주 나는 오류

| 메시지 | 원인 | 대처 |
|---|---|---|
| `Formula.Firewall …` | 엑셀 개인정보 보호 수준 설정 | [데이터] > [데이터 가져오기] > [쿼리 옵션] > 현재 통합 문서 > 개인 정보 > **"개인 정보 수준 무시"** 선택 후 새로고침. 이 파일은 내부 폴더 하나만 읽습니다 |
| `Expression.Error` + '설정'(또는 다른 쿼리 이름)을 인식하지 못했다는 메시지 | 쿼리 이름이 다름 | 쿼리 이름을 `[쿼리 이름: …]`과 똑같이 맞춤 |
| `[파일 없음] 원천 폴더에 읽을 .xlsx 파일이 없습니다` | 폴더 경로 오타 또는 빈 폴더 | `설정`의 `원천폴더` 확인 |
| `[시트 없음] …` / `[필수 열 없음] …` | 해당 파일의 시트 이름이나 열 이름이 다름 | 메시지에 나온 파일을 열어 확인. 사내 시스템 양식이 바뀌었으면 `설정`의 `시트이름`·`필수열`을 수정 |

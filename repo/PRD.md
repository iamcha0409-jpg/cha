# PRD: 선불카드사 이용건수 원천 데이터 자동 취합

- 작성일: 2026-11-17
- 관련 문서: [BRD.md](./BRD.md)
- 상태: 확정 (입력 형식 확인 완료)

> 예시의 숫자는 모두 **가짜 값**입니다.

---

## 1. 핵심 사용자 시나리오

### 시나리오 1. 매주 정기 취합
1. PM이 사내 시스템에서 이번 주 원천 파일 3개 이상을 내려받는다.
2. 내려받을 때 원천 폴더에 바로 저장한다. **파일 이름은 바꾸지 않아도 된다** (최신 파일은 파일 수정 시각으로 판단).
3. 취합 파일을 열고 [데이터] > [모두 새로고침]을 누른다.
4. 지난주까지 쌓인 데이터에 이번 주 데이터가 더해진 결과를 확인한다.

### 시나리오 2. 지난 수치가 수정된 경우
1. 이번 주에 받은 파일에 11/10 선불카드사2의 이용건수가 지난주와 다르게 들어 있다.
2. PM은 평소처럼 파일을 넣고 새로고침만 한다.
3. 결과에는 11/10 선불카드사2 행이 **1개만**, **가장 최근 파일의 값**으로 남는다.

### 시나리오 3. 월간 점유율 보고서 준비
1. 매월 보고 전에 취합 결과에서 최근 12개월 데이터를 쓴다.
2. 이 데이터가 월별 점유율 계산과 추이 차트(다음 단계)의 입력이 된다.

## 2. 입력 데이터 형식

### 원천 파일 (사내 시스템 다운로드)
- 개수: 매번 3개 이상, 파일마다 **기간만 다름**
- 열 구성: 고정
- 파일 형식: `.xlsx` (모든 파일이 같은 형식이어야 함)
- 데이터가 들어 있는 시트 이름: `우리카드(가칭) 점유율 현황`

| 기준일 | 선불카드사1 | 선불카드사2 | 선불카드사3 | 선불카드사4 |
|---|---|---|---|---|
| 2026-11-10 | 1,200 | 980 | 640 | 410 |
| 2026-11-11 | 1,150 | 1,020 | 600 | 395 |

- `기준일`: `YYYY-MM-DD` 모양
- `선불카드사1~4`: 일자별 **이용건수** (선불카드사1 = 우리 운영 카드)

### 최신 파일 판단 기준 (2026-11-18 변경)
- 파일 이름 규칙은 없다. 사내 시스템이 주는 이름 그대로 저장해도 된다 (예: `시스템다운로드.xlsx`, `시스템다운로드 (1).xlsx`).
- 같은 기준일·카드사가 여러 파일에 있으면 **파일 수정 시각이 가장 늦은 파일**(= 가장 최근에 내려받은 파일)의 값을 쓴다. 수정 시각이 같으면 파일 이름 역순.
- 운영 규칙: **원천 파일은 열어서 저장하지 않는다.** 저장하면 수정 시각이 바뀌어 그 파일이 최신으로 취급된다.
- 내려받은 파일을 복사·이동해도 수정 시각은 유지된다 (Windows 탐색기 기준).

## 3. 출력 결과물 형식

취합 파일(`주간보고_취합.xlsx`, 원천 폴더 바깥에 저장)의 시트 1개, **세로형(롱 포맷)** 표:

| 기준일 | 카드사 | 이용건수 | Source.Name |
|---|---|---|---|
| 2026-11-10 | 선불카드사1 | 1,200 | 2026-11-17_원천1.xlsx |
| 2026-11-10 | 선불카드사2 | 980 | 2026-11-17_원천1.xlsx |
| 2026-11-10 | 선불카드사3 | 640 | 2026-11-17_원천1.xlsx |
| 2026-11-10 | 선불카드사4 | 410 | 2026-11-17_원천1.xlsx |

- 기준일 × 카드사 조합마다 1행
- `Source.Name`: 그 값이 어느 파일에서 왔는지 추적하는 열
- 세로형으로 만드는 이유: 피벗과 차트로 카드사별 분석을 하기 쉽고, 나중에 선불카드사5가 생겨도 오류 없이 자동으로 포함된다.

### 일별점유율 시트
점유율 = 그날 카드사 이용건수 ÷ 그날 전체 카드사 이용건수 합계

| 기준일 | 선불카드사1 | 선불카드사2 | 선불카드사3 | 선불카드사4 | 합계 | 상태 |
|---|---|---|---|---|---|---|
| 2026-11-01 | 37.15% | 30.34% | 19.81% | 12.69% | 100.00% | 정상 |
| 2026-11-07 | 53.58% | (빈칸) | 28.15% | 18.27% | 100.00% | 카드사 누락 |

### 점유율현황 시트 (보고용 메인)
일별 점유율 줄 사이에, 각 달의 **데이터가 있는 마지막 기준일 바로 아래**에 그달 월 점유율 줄을 넣는다.

마지막 열 `전일대비 2배 초과`에 해당 카드사 이름이 나오고, 그 카드사 점유율 칸은 음영 처리된다.

열 구성: `구분 | 기준일 | 선불카드사1~4 건수 | 건수 합계 | 선불카드사1~4 점유율 | 점유율 합계 | 상태 | 전일대비 2배 초과` (일별·월별점유율 시트도 같은 건수 → 점유율 순서)

| 구분 | 기준일 | 카드사1 건수 | … | 건수 합계 | 카드사1 점유율 | … | 점유율 합계 | 상태 |
|---|---|---|---|---|---|---|---|---|
| 일 | 2026-10-31 | 1,150 | … | 3,138 | 36.65% | … | 100.00% | 정상 |
| **월** | **2026-10 월 합계** | **1,150** | … | **3,138** | **36.65%** | … | **100.00%** | 기준일 1일 |
| 일 | 2026-11-01 | 1,200 | … | 3,230 | 37.15% | … | 100.00% | 정상 |

### 월별점유율 시트
점유율 = 그달 카드사 이용건수 합계 ÷ 그달 전체 카드사 이용건수 합계

| 월 | 선불카드사1 | 선불카드사2 | 선불카드사3 | 선불카드사4 | 합계 | 기준일수 | 카드사누락일수 |
|---|---|---|---|---|---|---|---|
| 2026-10 | 36.65% | 30.91% | 19.76% | 12.68% | 100.00% | 1 | 0 |

- 점유율은 엑셀 % 형식으로 나온다. 소수점 자릿수는 엑셀 표시 형식에서 조정한다.
- "카드사 누락"인 날은 남은 카드사끼리 100%가 되므로 점유율이 부풀려진다. 해석할 때 상태와 카드사누락일수를 함께 본다.

## 4. 주요 기능 목록

### MVP (이번 범위)
| # | 기능 | 설명 |
|---|---|---|
| F1 | 폴더 결합 | 원천 폴더의 파일을 모두 아래로 이어 붙임 |
| F2 | 임시 파일 제외 | 이름이 `~$`로 시작하는 파일은 제외 |
| F3 | 형식 지정 | 기준일 → 날짜, 선불카드사1~4 → 숫자 |
| F4 | 세로형 변환 | `기준일`, `Source.Name`을 뺀 열을 피벗 해제 → `카드사`, `이용건수` |
| F5 | 최신값 우선 | 파일 수정 시각 내림차순(같으면 Source.Name 내림차순) 정렬 → `Table.Buffer`로 고정 → 기준일 + 카드사 기준 중복 제거 |
| F6 | 누적 | 원천 폴더의 지난 파일을 지우지 않으면 자동 누적 |
| F7 | 검증 절차 | 중복 0건 확인, 수정된 기준일 값 대조 (BRD 성공 기준 2·3) |
| F8 | 일별 점유율 | 카드사별 일별 점유율, 합계 100% 확인 열, 카드사 누락일 표시 |
| F9 | 월별 점유율 | 카드사별 월별 점유율(월 합계 기준), 기준일수·카드사누락일수 표시 |
| F10 | 점유율현황 | 일별 점유율 + 그달 마지막 기준일 바로 아래 월 점유율 줄 (2026-11-18 요청) |
| F11 | 음수 제외 | 최신 값이 음수인 기준일·카드사는 결과에서 제외, 검증 시트에 개수 표시 (2026-11-18 요청) |
| F13 | 이용건수 표시 | 점유율 시트 3종에 카드사별 이용건수·건수 합계 열 추가, 월 줄은 그달 합계 (2026-11-18 요청) |
| F12 | 전일 대비 2배 초과 음영 | 전날보다 이용건수가 2배 넘게 늘어난 카드사 칸을 점유율현황에서 음영 표시 (2026-11-18 요청) |

### 추후 (다음 단계)
- 전월 대비 점유율 변화(%p)
- 최근 12개월 점유율 추이 차트 (대시보드)
- 소수 값 경고
- 증감 코멘트 자동 문장화
- VOC·경쟁사 동향을 연결한 원인 분석과 향상 방안 (AI 프롬프트 활용, 회사 규정 확인 후)

| 저장 구조 | `원천 폴더/` (원천 파일만) + `주간보고_취합.xlsx` (원천 폴더 바깥) |

## 6. 단계별 구현 순서

| 단계 | 할 일 | 완료 확인 |
|---|---|---|
| 1 | 원천 폴더를 만들고, 내려받은 원천 파일을 넣기 (이름은 그대로) | 폴더에 원천 파일만 있음 |
| 2 | 새 통합문서 → [데이터] > [데이터 가져오기] > [파일에서] > [폴더에서] → [데이터 결합 및 변환] → 예제 파일 창에서 `우리카드(가칭) 점유율 현황` 시트 선택 | 모든 파일이 이어 붙은 미리보기가 보임 |
| 3 | F2 임시 파일 제외: `Name` 필터 > 시작 문자 아님 `~$` | 필터 단계가 생김 |
| 4 | F3 형식 지정 | 열 머리글 아이콘이 날짜/숫자로 바뀜 |
| 5 | F4 피벗 해제 → 열 이름 `카드사`, `이용건수`로 변경 | 4열 세로형 표 |
| 6 | F5 정렬 → 수식 입력줄에서 `= Table.Buffer(Table.Sort(...))`로 수정 → 기준일 + 카드사 중복 제거 | 단계 목록에 정렬·중복 제거가 있음 |
| 7 | [닫기 및 로드] | 시트에 결과 표가 생김 |
| 8 | **검증**: 기준일 × 카드사 중복 0건, 수정된 기준일 하나를 최신 파일 값과 대조 | 두 항목 통과 |
| 9 | 다음 주 실제 운영 1회: 파일 넣기 → 새로고침 | 누적 + 최신값 반영 확인 |
| 10 | 운영 절차 1장 정리 (원천 파일 저장 금지, 새로고침, 오류 시 대처) | 문서 완성 |
| 11 | F8·F9 일별점유율, 월별점유율 쿼리 추가 | 날마다·달마다 합계 100% |
| 12 | F10 점유율현황 쿼리 추가, 월 줄 조건부 서식 | 월 줄이 그달 마지막 기준일 바로 아래 |
| 13 | F11 음수 제외, F12 2배 초과 열 + 음영 조건부 서식 | T13에서 11/04 선불카드사1·4만 음영, 음수 값 1 |

### 알려진 리스크
- 사내 시스템의 다운로드 양식(열 이름)이 바뀌면 새로고침 오류가 난다. 이때는 4~5단계 열 설정을 다시 맞춘다.
- 원천 파일을 열어서 저장하면 수정 시각이 바뀌어 최신 파일 판단이 틀어질 수 있다.
- 원천 파일 형식이 섞이면(.xlsx + .csv) 결합 오류가 난다.
- 폴더 결합은 모든 파일에서 **같은 이름의 시트**(`우리카드(가칭) 점유율 현황`)를 찾는다. 시트 이름이 다른 파일이 섞이면 오류가 난다.

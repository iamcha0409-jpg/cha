## 1. 설계 결정 (PRD에 없던 예외 처리 방식)

PRD에서 정하지 않은 예외 상황은 아래 원칙으로 정했습니다. **"조용히 버리지 않는다"**가 기본 원칙입니다. 결과에서 제외한 데이터는 반드시 `검증` 시트에 개수와 이름으로 드러나게 했습니다. 다르게 처리하길 원하시면 말씀해 주세요.

| # | 상황 | 처리 | 검증 시트 표시 |
|---|---|---|---|
| D1 | 원천 폴더 안의 **하위 폴더**(예: `보관\`)에 있는 파일 | 읽지 않음 | – |
| D2 | `.xlsx`가 아닌 파일 (.csv, .txt 등) | 읽지 않음 | "제외된 파일" 목록 |
| D3 | `~$`로 시작하는 임시 파일 | 읽지 않음 | – (정상 동작) |
| D4 | (2026-11-18 변경) 파일 이름 규칙 없음 | 최신 파일은 **파일 수정 시각**으로 판단. 이름은 무관 | – |
| D5 | 완전히 빈 행 | 제거 | – (정상 동작) |
| D6 | 숫자는 있는데 기준일이 빈 행 | 결과에서 제외 | "기준일 없는 값" 개수 (행 안의 값 개수 기준) |
| D7 | 날짜·숫자로 바꿀 수 없는 값 (예: `N/A`, `2026-13-40`) | 숫자 오류는 그 값만, 기준일 오류는 그 행의 값 전체를 결과에서 제외 | "형식 오류 값" 개수 |
| D8 | 카드사 값이 빈 칸 | 그 기준일·카드사 행이 생기지 않음 | "카드사 4개가 다 없는 기준일" 개수 |
| D9 | 지정 시트(`우리카드(가칭) 점유율 현황`)가 없는 파일 | **새로고침 전체 중단**, 파일명이 담긴 오류 메시지 | (새로고침 오류 창) |
| D10 | 필수 열(기준일, 선불카드사1~4)이 빠진 파일 | **새로고침 전체 중단**, 빠진 열 이름이 담긴 오류 메시지 | (새로고침 오류 창) |
| D11 | 새 카드사 열 추가 (예: 선불카드사5) | 자동 포함. **기준일 외의 모든 열을 카드사로 봅니다** (예: `비고` 열이 생기면 카드사로 잡힘 → 카드사 목록에서 확인) | "카드사 목록" |
| D14 | 이용건수가 음수 | **최신값을 고른 뒤** 결과에서 제외 (예전 파일 값으로 대체하지 않음). 그날은 "카드사 누락" | "음수 값 (결과에서 제외)" 개수 → "확인 필요" |
| D15 | 전날(달력 기준)보다 이용건수가 2배 초과 | 값은 그대로 두고 점유율현황에 **음영 표시**. 전날 데이터가 없으면 비교 안 함, 전날 0건이면 늘어나면 모두 표시, 정확히 2배는 표시 안 함 | 점유율현황 "전일대비 2배 초과" 열 |
| D13 | 머리글이 빈 열 (엑셀이 `Column6`처럼 자동으로 붙이는 이름) | 읽지 않음 | – |
| D12 | 수정 시각이 같은 파일 2개에 같은 기준일·카드사가 있음 | 파일 이름 역순(뒤에 정렬되는 이름)이 우선 | "여러 파일에 겹친 값", 값이 다르면 "수정 반영된 값" |

D9·D10은 결과를 내지 않고 멈추게 했습니다. 시트나 열이 통째로 빠지면 그 파일 데이터 전체가 사라지는데, 이것을 경고만으로 넘기면 놓치기 쉽기 때문입니다.

## 2. 기능별 검증 기준

| 기능 | 검증 기준 (통과 조건) |
|---|---|
| **F1 폴더 결합** | 원천 폴더 최상위의 `.xlsx` 파일이 모두 읽히고, 결과 행 수 = 각 파일 유효 값 수의 합(중복 제거 전) |
| **F2 임시 파일 제외** | `~$`로 시작하는 파일이 있어도 새로고침 오류가 나지 않고, 그 파일 데이터는 결과에 없음 |
| **F3 형식 지정** | `기준일`은 날짜 형식, `이용건수`는 정수 형식. `"1,200"` 같은 텍스트 숫자도 1200으로 변환됨 |
| **F4 세로형 변환** | 결과 열이 정확히 `기준일 \| 카드사 \| 이용건수 \| Source.Name`. 카드사 값은 원천 열 이름 그대로 |
| **F5 최신값 우선** | 같은 기준일·카드사가 여러 파일에 있으면 **파일 수정 시각이 가장 늦은 파일의 값**만 남음 |
| **F6 누적** | 지난 파일을 지우지 않으면 지난 기준일 데이터가 결과에 계속 남음 |
| **F7 검증** | `검증` 시트에서 "기준일·카드사 중복 = 0"이고, 나머지 경고 항목이 모두 0이면 판정 "정상" |
| **F8 일별 점유율** | 날마다 합계 = 100%, 카드사 값 = 그날 건수 ÷ 그날 합계, 카드사가 빠진 날은 상태 "카드사 누락" |
| **F10 점유율현황** | 각 달의 월 점유율 줄이 그달 **데이터가 있는 마지막 기준일 바로 아래**에 1줄씩, 월 줄 값 = 월별점유율 값, 상태에 기준일수·카드사 누락일수 표시 |
| **F13 이용건수 표시** | 일·월 줄 모두 카드사별 건수와 건수 합계가 점유율 앞에 나오고, 월 줄 건수 = 그달 합, 점유율 = 건수 ÷ 건수 합계 |
| **F11 음수 제외** | 취합결과에 음수 값 없음, 최신 값이 음수면 그 기준일·카드사 행 자체가 없음 |
| **F12 2배 초과 음영** | 오늘 이용건수 > 전날 × 2 인 카드사만 "전일대비 2배 초과" 열에 나오고, 그 칸만 음영 |
| **F9 월별 점유율** | 달마다 합계 = 100%, 카드사 값 = 그달 건수 합 ÷ 그달 전체 합 (일별 점유율의 평균이 아님), 월 경계(10/31·11/01)가 다른 달로 나뉨 |

## 3. 테스트 케이스 (정상 · 예외 · 오류)

테스트용 가짜 데이터는 `테스트데이터\` 폴더에 케이스별로 들어 있습니다. 기대 결과는 `테스트데이터\기대결과.xlsx`에 있습니다.

### 정상 입력

| ID | 상황 | 입력 | 기대 결과 |
|---|---|---|---|
| T01 | 기본 취합 | `2026-11-03_원천1~3.xlsx` (기간이 겹치지 않는 3개 파일, 기준일 9일치) | 9일 × 4개사 = **36행**, 검증 "정상" |
| T02 | 지난 수치 수정 | T01(수정 시각 11/03) + `2026-11-10_원천1.xlsx`(수정 시각 11/10, 기준일 11/08~11/10, 이 중 11/08 선불카드사2 값이 다름) | 10일 × 4개사 = **40행**, 11/08 선불카드사2 = **새 파일 값**, 검증 "여러 파일에 겹친 값 = 8"(11/08·11/09 × 4개사), "수정 반영된 값 = 1", 판정 "정상" |
| T03 | 텍스트 숫자 | 이용건수가 `"1,200"`처럼 쉼표가 있는 텍스트 | 1200(숫자)으로 변환, **12행**, 검증 "정상" |
| T04 | 새 카드사 추가 | `선불카드사5` 열이 있는 파일 | 3일 × 5개사 = **15행**, 카드사 목록에 선불카드사5 포함 |

### 예외 입력 (결과는 나오지만 걸러지거나 경고)

| ID | 상황 | 입력 | 기대 결과 |
|---|---|---|---|
| T05 | 임시 파일 | 정상 파일 + `~$2026-11-03_원천1.xlsx` | 임시 파일 무시, **12행**, 판정 "정상" |
| T06 | 하위 폴더·다른 형식 | 정상 파일 + `보관\` 폴더 안 파일 + `메모.csv` | 보관 폴더 파일 무시(**12행**), `메모.csv`는 "제외된 파일"에 표시 → 판정 "확인 필요" |
| T07 | 이름과 무관하게 수정 시각 우선 | `시스템다운로드.xlsx`(11/03 수정) + `시스템다운로드 (1).xlsx`(11/10 수정, 11/03 값이 다름). 이름 순서로는 앞 파일이 이기는 구성 | **16행**. 11/03은 **수정 시각이 늦은 `(1)` 파일 값**, 수정 반영된 값 4, 판정 "정상" |
| T08 | 빈 행 / 기준일 없는 행 | 중간에 완전 빈 행 1개, 기준일만 빈 행 1개 | 빈 행은 조용히 제거, 기준일 없는 행은 제외 → **12행**, "기준일 없는 값 = 4" → "확인 필요" |
| T09 | 형식 오류 값 | 이용건수에 `N/A` 1칸, 기준일에 `2026-13-40` 1행 | 오류 값 제외 → **11행**, "형식 오류 값 = 5"(N/A 1 + 잘못된 기준일 행의 값 4) → "확인 필요" |
| T10 | 빈 칸 | 11/02 선불카드사3이 빈 칸 | **11행**(11/02는 3개사만), "카드사 누락 기준일 = 1" → "확인 필요" |
| T13 | 더미 10건 (정상 2·엣지 3·이상값 5) | 정상·엣지·이상값을 섞은 10행 | **30행**(음수 1개 제외), 판정 "확인 필요", 음수 값 1, 월별 2026-10 / 2026-11 두 줄, **11/04 선불카드사1·4 음영** (1,210→1,250,000 / 0→405) |

### 오류 입력 (새로고침이 멈춰야 정상)

| ID | 상황 | 입력 | 기대 결과 |
|---|---|---|---|
| T11 | 시트 없음 | 시트 이름이 `Sheet1`인 파일 | 새로고침 오류: `"…xlsx: '우리카드(가칭) 점유율 현황' 시트를 찾을 수 없습니다."` |
| T12 | 필수 열 없음 | `선불카드사4` 열이 없는 파일 | 새로고침 오류: `"…xlsx: 필수 열이 없습니다 → 선불카드사4"` |

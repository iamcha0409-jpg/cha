# BRD: 선불카드사 이용건수 원천 데이터 자동 취합

## 1. 프로젝트 배경 (현재 문제)

- 주간·월간 보고서를 만들려면 사내 시스템에서 **원천 파일 3개 이상**을 내려받아 하나로 합쳐야 한다.
- 지금은 복사·붙여넣기로 직접 합치고 있고, **취합 단계에만 주 20~40분**이 든다.
- 원천 파일은 열 구성(기준일, 선불카드사1~4)이 고정되어 있고, 파일마다 **기간만 다르다**.
- 사내 시스템이 **지난 기준일의 수치를 가끔 수정**한다. 손으로 합치면 수정 전 값과 수정 후 값이 섞이거나, 같은 행이 두 번 들어갈 위험이 있다.
- 엑셀 함수·매크로와 데이터 분석·시각화에 부담이 있어서, 함수를 많이 쓰는 방식으로는 유지하기 어렵다.
- 회사 환경 제약: **사내망이 분리**되어 있고 **프로그램 설치가 제한**된다. 내부망 파일을 밖으로 옮기려면 **사전승인**을 받아야 한다(내부망으로 들여오는 것은 승인 불필요). AI는 회사 인터넷망에서 사용할 수 있다.

## 3. 비즈니스 가치

| 구분 | 현재 | 목표 | 근거 |
|---|---|---|---|
| 시간 절감 | 취합에 주 20~40분 | 파일 저장 + [모두 새로고침]만 남김 | 인터뷰 답변 기준 |
| 연간 환산 | 주 20~40분 × 52주 = **연 약 17~35시간** | 같은 시간만큼 절감 (내려받기 시간 제외) | 단순 계산 |
| 품질: 수정값 반영 | 수정된 지난 수치를 사람이 찾아서 고쳐야 함 | 같은 기준일·카드사는 **가장 최근 파일 값**으로 자동 반영 | 지난 수치가 가끔 수정됨 |
| 품질: 오류 감소 | 붙여넣기 누락이나 중복 위험 | 붙여넣기 단계가 없어짐 | 수작업 단계 제거 |
| 후속 효과 | – | 월간 점유율 보고서, 대시보드, 코멘트 자동화의 입력 데이터가 됨 | 자동화 후보 ②③의 선행 조건 |

> 참고: 보고서 작업 전체는 **주 1시간 미만**으로 확인됨. 단계별 답(취합·지표/차트·요약 문구 각 20~40분)은 더하면 1시간을 넘어서 전체 시간과 맞지 않으므로, 취합 단계의 실제 시간은 한 번 재보는 것을 권장. 위 표는 취합 단계에 대한 답(20~40분)을 그대로 사용함.

## 4. 성공 기준 (1~4, 6은 [제안] / 5는 확정)

1. **조작 단순화**: 새 원천 파일을 폴더에 넣고 [모두 새로고침]만 누르면 취합이 끝난다 (함수 입력 없음).
2. **정확성**: 같은 기준일 × 카드사 조합이 결과에 **딱 1행**씩만 있다 (중복 0건).
3. **수정값 반영**: 수정된 적 있는 기준일 하나를 골랐을 때, 결과 값이 **가장 최근 파일의 값과 같다**.
4. **누적 유지**: 지난주 데이터가 사라지지 않고 계속 쌓인다.
5. **시간**: 자동화 후 취합 단계가 **주 30분 이내**로 끝난다 (확정된 목표).
6. **환경 준수**: 프로그램 설치와 매크로(VBA) 없이 엑셀 기본 기능만으로 동작한다.

## 5. 범위 / 비범위

### 이번에 할 것 (범위)
- 폴더 안의 원천 파일(같은 양식, 3개 이상)을 **자동으로 이어 붙이기**
- 지난 데이터 **누적**
- 같은 기준일·카드사가 여러 번 나오면 **최신 파일 값만 남기기**
- 열 정리: 날짜·숫자 형식 지정, `기준일 | 카드사 | 이용건수` 형태로 변환 (열 피벗 해제)
- 임시 파일(`~$`) 제외 처리
- 결과 검증 방법과 운영 절차 문서화
- 카드사 1~4별 **일별 점유율**과 **월별 점유율** 계산 (2026-11-18 추가 요청)

### 이번에 하지 않을 것 (비범위)
- 사내 시스템에서 파일을 **내려받는 작업**의 자동화 (설치 제한, 사내 시스템 접근 방식이 확인되지 않음)
- 추이 차트, 전월 대비 표 (다음 단계: 대시보드)
- 증감 코멘트 자동 문장화
- VOC(콜센터, 고객의 소리)와 경쟁사 동향 분석, 향상 방안 작성
- 매크로(VBA)나 외부 프로그램 사용
- AI를 활용한 점유율 보고서 작성 (후속 단계. 회사 인터넷망에서 AI 사용은 가능하지만, 내부망 파일을 옮기려면 사전승인이 필요함)

# 선불카드사 이용건수 원천 데이터 자동 취합

사내 시스템에서 내려받은 원천 파일(3개 이상)을 엑셀 파워쿼리로 자동 취합하고, 카드사별 일별·월별 점유율을 계산하는 프로젝트입니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `BRD.md` | 비즈니스 요구사항 (배경, 사용자, 성공 기준) |
| `PRD.md` | 제품 요구사항 (시나리오, 기능 명세) |
| `구현가이드.md` | 파워쿼리 구현 순서와 설정 방법 |
| `검증기준_테스트케이스.md` | 검증 기준과 테스트 케이스(T01~T13) |
| `양식_미리보기.xlsx` | 결과 양식 미리보기 |
| `파워쿼리/` | 쿼리별 M 코드 (`0_설정` ~ `8_점유율현황`) |
| `테스트데이터/` | 케이스별 원천 파일과 `기대결과.xlsx` |

## 사용 방법

1. `파워쿼리/` 폴더의 M 코드를 번호 순서대로 엑셀 파워쿼리(빈 쿼리 → 고급 편집기)에 붙여넣습니다.
2. `0_설정`에서 원천 폴더 경로를 지정합니다.
3. [데이터] > [모두 새로고침]을 누릅니다.

자세한 내용은 `구현가이드.md`를 참고하세요.

> 테스트데이터의 수치는 모두 가짜 값입니다. `T05_임시파일`의 `~$` 파일은 임시파일 제외 동작을 검증하기 위해 의도적으로 넣은 파일입니다.
